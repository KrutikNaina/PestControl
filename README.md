# 🐜 Pest Control Website  

This project is a **Pest Control Service Website** where users can:  
✅ Learn about the company.  
✅ Inquire about pest control services.  
✅ Contact the company for services.  

---

## 📌 Features  
- **Home Page** – Information about the company.  
- **Services Page** – List of pest control services.  
- **Inquiry Form** – Users can submit service requests.  
- **Contact Page** – Company contact details and form.  

---

## 🛠️ Technologies Used  
- **Frontend**: HTML, CSS, JavaScript (Bootstrap)  
- **Backend**: PHP  
- **Database**: MySQL  
- **Version Control**: Git & GitHub  

---
